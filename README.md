# DIP Practicals 14A-15B (backup version, no login)

Interactive session for Digital Image Processing practicals 14A-15B.
Students learn and try concepts in the browser, then write and run programs in MATLAB or Python.

This version needs no Firebase or sign-in. Extra-task answers are saved in the student's browser; students download them from "My answers" as a .txt file and submit it to the teacher.

Upload `index.html`, `README.md` and the `assets/` folder to the repository root.
